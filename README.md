# 시간의 오카리나 Switch 2 한국어 공략

- 로컬 위치: 작업 PC의 `ai_project\게임공략 만들기\zelda-oot-switch2`
- 판본: 2026-11-05 발매 Nintendo Switch 2 리메이크, 한국어 독자용
- 개발 주체: 닌텐도 개발진. 일본 제작으로 분류함. [한국닌텐도 개발자 인터뷰](https://www.nintendo.com/kr/interview/aa9ja/)를 근거로 사용하며 전체 외주 제작사를 확정한 것은 아님.

- 제외: 실제 지형·방별 완전 지도, 황금 스탈튤라 전수 위치, 모든 루피·열쇠 상자, 추가 모드·amiibo의 완전 공략
- 대상 패치: 버전 번호 미확인. 자료 열람 기준일 2026-11-18
- 한국어 지원: 한국닌텐도 공식 한국어 소개와 한국어 공략 자료 확인. 한국어 실기 플레이 화면의 용어 전수 대조 미실행
- 버전: 0.2.0 / 2026-11-18

## 파일과 명령

Python 3의 표준 라이브러리만 사용함. 설치할 패키지 없음.

```powershell
# 저장소 폴더에서 실행
python build.py
python verify.py
node --check src/app.js
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

미리보기: `http://127.0.0.1:8765/`

## 업데이트 규칙

`src/content.py`를 수정하고 재빌드함. 생성된 `dist/index.html`과 `docs/sources.json`은 직접 수정하지 않음. 고정 `chapter.id`, `step.id`는 유지함. 진행 키는 `zelda-oot-switch2:progress:v1`, 값은 단계 ID의 배열이며 순서와 표시 이름을 바꾸어도 체크가 유지됨. 브라우저·프로필·미리보기 주소가 바뀌면 저장 공간도 달라지므로 공개 사이트로 자동 이전되지 않음.

각 단계는 소속 장의 출처·확인일·판본·명칭 상태를 상속함. 준비 권장은 팁으로 표시하며 공략 사실과 구분함. 같은 원문을 번역한 한국어 자료를 독립 검증으로 중복 계산하지 않음.

## 다음 업데이트 작업

1. 이 폴더에서 `git status --short`, `git fetch origin`, `git log --oneline HEAD..origin/main`으로 로컬·원격 차이를 확인함. 변경이 있으면 내용을 비교하고 통합함. 강제 푸시하지 않음.
2. `src/` 원본을 수정함. 공략 사실을 바꾸면 Switch 2 전용 근거와 확인일을 함께 갱신함.
3. `src/content.py`의 `META` 버전·날짜, 이 문서 변경 기록을 갱신함. 출처 탭의 사이트별 문서 수는 빌드에서 자동 집계함.
4. 빌드·정적 검사·JS 문법 검사를 실행함. 화면 변경이면 로컬 서버에서 해당 기능도 확인하고 `docs/QA.md`에 실제 검사만 기록함.
5. `git diff --check`, `git diff --stat`과 변경 내용을 검토하고 필요한 파일만 스테이징·커밋함.
6. `git push origin main` 후 `git rev-parse HEAD`와 `git ls-remote origin refs/heads/main`의 SHA가 일치하는지 확인함.

내용 원본과 생성물, 출처 근거, 버전 기록을 함께 보관하므로 이후 이 폴더에서 이어서 수정할 수 있음. 작업 지침은 `AGENTS.md`를 참조함. 자동 갱신·자동 게시 일정은 설정하지 않음.

수집 체크 키는 `zelda-oot-switch2:collection:v1`이며 항목 ID 배열을 저장함. 장비·하트·이벤트 체크는 서로 독립적이고 메인 진행 완료를 자동 변경하지 않음. 새 수집 항목 ID를 변경하지 말 것. `src/assets/diagrams/`는 `src/illustrations.py`에서 재생성함.
