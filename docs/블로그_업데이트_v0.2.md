# 시간의 오카리나 공략집 v0.2 업데이트 안내

시간의 오카리나 Switch 2 공략집에 장비·서브 퀘스트·지역 수집·숨겨진 요소를 추가했습니다.

장비와 도구 30종의 입수처, 가면 교환과 빅고론도 교환을 포함한 서브 퀘스트 7개를 볼 수 있습니다. 지역 수집 탭에서는 하트 조각 36개 항목과 핵심 장비 상자 19곳을 찾고 획득 여부를 기록할 수 있습니다. 하트가 든 상자는 해당 하트 항목과 연결했습니다.

물의 신전 수위와 영혼의 신전 시대 전환 등은 설명 그림으로 보완했습니다. 그림은 실제 지도와 구분되며 눌러서 크게 볼 수 있습니다. 공식 소개 화면은 장면 참고용입니다.
