# 조사·검증 메모 — 2026-11-18

## 자료 선정

- 사용자가 Switch 2 리메이크판을 선택함. 처음 가정한 3DS판 자료를 본문 기준으로 사용하지 않음.
- 한국닌텐도 공식 소개·개발자 인터뷰에서 출시 판본과 수동 점프 등 확인함.
- 한국어 개인 공략(정직한 게임 리뷰어) 및 한국어 제공 공략(OoT Guide)을 먼저 탐색한 뒤 nJOY의 `zdot_` 경로와 GameWith Switch 2 전용 본문을 대조함.
- nJOY의 `zd5_`는 N64/3DS 자료이므로 채택하지 않음.
- OoT Guide는 여러 항목에서 GameWith 재가공을 명시함. 두 사이트의 일치를 독립 검증 2건으로 세지 않음. 운영자 소재지와 원문 언어는 별개로 기록함.
- 해외 문장을 그대로 번역·전재하지 않고 핵심 행동을 한국어로 재구성함. 출처별 짧은 요약 범위로 제한함.

## 검증 한계

- 게임 실기·패치 번호·한국어 UI의 모든 명칭을 직접 확인하지 않음.
- 본문은 핵심 진행 요약이며 방별 모든 이동·모든 열쇠 위치·모든 수집품을 담은 완전 공략이 아님.
- 그림과 실제 한국어 화면은 미수록. 무단 지도 복제나 가상의 게임 스크린샷을 만들지 않음.
- 출처 URL은 실제 열람한 문서임. 공개된 문서의 내용이 수정되면 근거도 재대조해야 함.

실제 실행 결과는 `QA.md`에 기록함. 정적 검사와 브라우저에서 수행한 항목을 구분함.

## v0.2 보강 근거와 제한

- `src/collection.py` 각 항목에 판본·나이·필요 장비·URL 키·열람일·명칭 상태를 보관함. 상세 URL은 `sources.json`에서 대조 가능함.
- GameWith의 리메이크 하트 개별 목록 36항목을 지역 문서와 대조함. 같은 페이지 상단 지역별 집계 수치에는 본문과 맞지 않는 값이 있어 그 수치를 복사하지 않음.
- nJOY의 하트·가면·일부 장비 목록에는 N64/3DS 정보를 기반으로 갱신 중이라는 경고가 있음. 제목에 Switch 2가 있다는 이유만으로 전체를 검증 완료로 취급하지 않음.
- 하이랄 평원 두 하트는 청년의 요정 메모·암호 확인 후 소년으로 회수하는 조건을 반영함. 과거의 구멍·수중 하트 설명을 그대로 옮기지 않음. 암호의 한국판 선택 문장은 미확인임.
- 분화구 세 번째 항목은 리메이크 개별 목록과 지역 문서에 있는 상인 보상임. 원작 얼음 동굴 하트를 총수 맞추기용으로 추가하지 않음.
- 빅고론도 운반 시간은 리메이크 전용 두 자료에서 버섯 4분, 개구리 2분30초, 안약 3분30초를 확인함. 원작 3분·3분·4분으로 표기하지 않음. 워프 시 잔여 시간 수치의 설명은 자료가 달라 숫자를 확정하지 않고 운반 중 워프를 피하도록 안내함.
- 빈 병 5개 및 빅포우 5마리 보상은 리메이크 안내를 사용함. 원작의 병 4개·빅포우 10마리 납품과 구분함.
- 부메랑·훅샷으로 먼 하트를 직접 회수한다고 안내하지 않음. 발판을 타거나 표적으로 이동한 뒤 하트가 있는 자리에 직접 접근하도록 정리함.
- 하트가 든 상자 6곳은 기존 하트 항목으로 연결함. 같은 물건을 별도의 두 체크로 만들지 않음. 핵심 장비 상자 19곳은 별도 항목임. 모든 루피 상자·작은 열쇠 상자의 전수 목록은 아님.
- 한국어 자료 OoT Guide가 인용하는 GameWith는 같은 근거 계열임. 새 자료가 일본어에 치우친 세부 항목은 한국판 실기 대조 완료로 표기하지 않음.

## 이미지

- 자체 제작 SVG 33개: 메인 진행 17개와 하트가 있는 지역 16개. 낙하·폭탄·수위·시대 전환 4개 도식은 원리를 단순화한 설명 그림임.
- 지역 지점도는 랜드마크를 번호로 대응한 목록도이며 북쪽·거리·좌표·실제 방 배치를 의미하지 않음.
- 한국닌텐도 공식 페이지의 소개 화면 4개를 원본 상태로 사용함. 권리자 Nintendo, 출처 URL·열람일·장면 대응을 데이터에 보관함. 적 위치나 상자 위치를 증명하는 화면으로 사용하지 않음.
- 사용자의 직접 플레이 스크린샷, 지도 위 정확한 핀, 모든 퀘스트·모든 증표의 실기 전수 검증은 아직 없음.
